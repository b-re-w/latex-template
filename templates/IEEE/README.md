# IEEE Conference Template (IEEEtran)

The official kit ships no README, so this file records what the directory holds.

- Class: `IEEEtran.cls`, conference mode
- Source: IEEE Manuscript Templates for Conference Proceedings, `conference_101719.tex`
  (the file name carries the kit's own revision stamp, 2019-10-17)

Unlike the other venues, the kit has no `.bib` file: its example lists references
inline with `thebibliography`. `references.bib` here is empty, and `main.tex` is
set up to use it with `\bibliographystyle{IEEEtran}`.
